# All Danielli Ayumi's vibe coding projects

## Vibe Coded Projects Collection

This collection brings together projects developed using **Vibe Coding** practices as a tool for prototyping, idea validation, and the exploration of digital solutions for real-world problems. The projects span multiple domains, including recruitment, personal finance, travel, and food delivery, showcasing how the collaboration between artificial intelligence and software engineering can accelerate the transformation of concepts into functional prototypes. Each application was designed to validate requirements, user flows, and market opportunities while maintaining a strong focus on user experience, information organization, and practical problem-solving.
